# stpanteleimon.gr

Страница сайта Свято-Пантелеимонова монастыря (Святая Гора Афон) на адресе stpanteleimon.gr.

Сам сайт работает на Google Apps Script; `index.html` показывает его на весь экран под адресом обители.
Пока сайт закрыт до открытия, посетители видят страницу «Сайт обители готовится к открытию»
(включается в таблице сайта: лист «Настройки» → «Сайт открыт для всех»).
