Как выложить на GitHub (stpanteleimon/stpanteleimon.github.io)

1. Папку «workers» загрузите целиком в корень хранилища (рядом с папками app, arch, sluzhba).
   Получится адрес stpanteleimon.gr/workers/ — экран службы рабочих (вход по коду с почты),
   и stpanteleimon.gr/workers/#form — анкета для подрядчиков (по-гречески, по-русски, по-английски).

2. Файл «sluzhba/index.html» замените новым (в папке sluzhba на GitHub).
   Теперь ссылка «Ответить» из письма о новой заявке сразу открывает эту заявку.

Остальные файлы на GitHub не трогать.
